# Security policy

## Reporting a vulnerability

Report suspected vulnerabilities through a public [GitHub Issue](https://github.com/mekstrem/iskrona/issues/new/choose). Use a clear title beginning with `Security:` and include:

- the affected ISKrona version and platform;
- a minimal, safe reproduction;
- the observed and expected behavior; and
- your assessment of the impact.

Do not publish credentials, personal data, private paths, or exploit payloads that could harm other users. If public disclosure would create immediate risk, describe the impact without including the harmful detail and wait for maintainer guidance in the issue.

## Supported versions

Security fixes are made for the latest released version and the `master` branch.
